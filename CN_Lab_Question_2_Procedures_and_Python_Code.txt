GENERAL SOCKET PROGRAM PROCEDURE
--------------------------------
1. Identify whether the question asks for TCP or UDP.
2. Write the server program first.
3. Create a socket:
   TCP: socket.socket(socket.AF_INET, socket.SOCK_STREAM)
   UDP: socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
4. Server uses bind() to attach to an IP address and port.
5. TCP server uses listen() and accept().
6. UDP server uses recvfrom() and sendto().
7. Client uses connect()/send()/recv() for TCP, or sendto()/recvfrom() for UDP.
8. Run the server in one terminal and the client in another.
9. Use 127.0.0.1 when both programs run on the same computer.

1. TCP CHAT PROGRAM - CLIENT TERMINATES THE CHAT
------------------------------------------------------------
AIM:
To develop a chat program using TCP sockets where the client can terminate the connection.

PROCEDURE:
1. Create a TCP socket in both client and server.
2. Server binds to port 5000 and listens for a client.
3. Client connects to the server.
4. Client and server exchange messages.
5. When the client types "exit", it sends the termination message and closes the connection.

SERVER CODE (tcp_chat_server.py):
-------------------------------
import socket

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.bind(("127.0.0.1", 5000))
s.listen(1)
print("Server waiting...")
conn, addr = s.accept()
print("Connected:", addr)

while True:
    msg = conn.recv(1024).decode()
    if not msg or msg.lower() == "exit":
        print("Client ended the chat")
        break
    print("Client:", msg)
    reply = input("Server: ")
    conn.send(reply.encode())

conn.close()
s.close()

CLIENT CODE (tcp_chat_client.py):
-------------------------------
import socket

c = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
c.connect(("127.0.0.1", 5000))

while True:
    msg = input("Client: ")
    c.send(msg.encode())
    if msg.lower() == "exit":
        break
    reply = c.recv(1024).decode()
    print("Server:", reply)

c.close()

RUN:
1. Terminal 1: python tcp_chat_server.py
2. Terminal 2: python tcp_chat_client.py

import socket

9. HAMMING (7,4) CODE - GENERATE, DETECT AND CORRECT
------------------------------------------------------------
AIM:
To generate a (7,4) Hamming code, introduce a one-bit error, detect it and correct it.

PROCEDURE:
1. Read four data bits from the user.
2. Place data bits in positions 3, 5, 6 and 7.
3. Calculate parity bits at positions 1, 2 and 4 using even parity.
4. Introduce an error at a position selected by the user.
5. Calculate the syndrome at the receiver.
6. If syndrome is non-zero, flip the indicated bit to correct the error.
7. Display the corrected code and original data.

CODE (hamming_74.py):
-------------------------------
data = input("Enter 4 data bits: ")
if len(data) != 4 or any(bit not in "01" for bit in data):
    print("Enter exactly four binary digits")
    raise SystemExit

d = [0] * 8
d[3], d[5], d[6], d[7] = map(int, data)

# Even parity bits
d[1] = d[3] ^ d[5] ^ d[7]
d[2] = d[3] ^ d[6] ^ d[7]
d[4] = d[5] ^ d[6] ^ d[7]

print("Generated Hamming code:", "".join(map(str, d[1:])))

pos = int(input("Enter error position (1-7): "))
if pos < 1 or pos > 7:
    print("Invalid position")
    raise SystemExit

d[pos] ^= 1
print("Code with error:", "".join(map(str, d[1:])))

s1 = d[1] ^ d[3] ^ d[5] ^ d[7]
s2 = d[2] ^ d[3] ^ d[6] ^ d[7]
s4 = d[4] ^ d[5] ^ d[6] ^ d[7]
syndrome = s1 + 2 * s2 + 4 * s4

print("Error position:", syndrome if syndrome else "No error")
if syndrome:
    d[syndrome] ^= 1

print("Corrected code:", "".join(map(str, d[1:])))
print("Original data:", "".join(str(d[i]) for i in [3, 5, 6, 7]))

10. HAMMING SENDER - READ TEXT, ENCODE AND SAVE TO CHANNEL
------------------------------------------------------------
AIM:
To convert text into binary, add Hamming redundant bits and save the result in a file named channel.

PROCEDURE:
1. Read a text message.
2. Convert each character into 8-bit binary.
3. Divide the bits into groups of four.
4. Encode each group using Hamming (7,4).
5. Save the encoded bits in the file channel.

CODE (hamming_sender.py):
-------------------------------
def encode(bits):
    d = [0] * 8
    d[3], d[5], d[6], d[7] = map(int, bits)
    d[1] = d[3] ^ d[5] ^ d[7]
    d[2] = d[3] ^ d[6] ^ d[7]
    d[4] = d[5] ^ d[6] ^ d[7]
    return "".join(map(str, d[1:]))

message = input("Enter text: ")
binary = "".join(format(ord(ch), "08b") for ch in message)
encoded = ""

for i in range(0, len(binary), 4):
    encoded += encode(binary[i:i+4])

with open("channel", "w") as f:
    f.write(encoded)

print("Encoded data saved in channel")

11. HAMMING RECEIVER - READ CHANNEL, CORRECT AND DISPLAY TEXT
------------------------------------------------------------
AIM:
To read the channel file, detect and correct a single-bit error and display the original text.

PROCEDURE:
1. Read encoded bits from the channel file.
2. Divide the data into 7-bit blocks.
3. Calculate the syndrome for each block.
4. Correct the bit if an error is detected.
5. Remove parity bits and collect the four data bits.
6. Convert every eight recovered bits into a character.

CODE (hamming_receiver.py):
-------------------------------
with open("channel", "r") as f:
    encoded = f.read().strip()

decoded_bits = ""

for i in range(0, len(encoded), 7):
    block = encoded[i:i+7]
    if len(block) != 7:
        continue

    d = [0] + [int(x) for x in block]
    s1 = d[1] ^ d[3] ^ d[5] ^ d[7]
    s2 = d[2] ^ d[3] ^ d[6] ^ d[7]
    s4 = d[4] ^ d[5] ^ d[6] ^ d[7]
    error = s1 + 2*s2 + 4*s4

    if error:
        print("Error at bit position:", error)
        d[error] ^= 1

    decoded_bits += "".join(str(d[j]) for j in [3, 5, 6, 7])

text = ""
for i in range(0, len(decoded_bits), 8):
    byte = decoded_bits[i:i+8]
    if len(byte) == 8:
        text += chr(int(byte, 2))

print("Original text:", text)

NOTE:
To test error correction, manually change one 0 to 1 or 1 to 0 in the channel file.
The receiver corrects one error in each 7-bit block.

12. SLIDING WINDOW PROTOCOL - SENDER
------------------------------------------------------------
AIM:
To implement sliding window flow control. Sender stores frames in Sender_Buffer.

PROCEDURE:
1. Read the window size and message.
2. Treat each character as one frame.
3. Add a frame number to each character.
4. Write the frames to Sender_Buffer.
5. The receiver reads the file and writes ACK/NACK responses.

CODE (sliding_sender.py):
-------------------------------
window = int(input("Enter window size: "))
message = input("Enter message: ")

with open("Sender_Buffer", "w") as f:
    for i, ch in enumerate(message):
        f.write(f"{i}: {ch}\n")

print("Frames saved in Sender_Buffer")
print("Window size:", window)

13. SLIDING WINDOW PROTOCOL - RECEIVER
------------------------------------------------------------
AIM:
To read Sender_Buffer, check frame numbers and write ACK/NACK into Receiver_Buffer.

PROCEDURE:
1. Open Sender_Buffer.
2. Read each frame and check its sequence number.
3. If the frame number is expected, write ACK.
4. Otherwise write NACK.
5. Save the responses in Receiver_Buffer.

CODE (sliding_receiver.py):
-------------------------------
expected = 0

with open("Sender_Buffer", "r") as source, \
     open("Receiver_Buffer", "w") as output:
    for line in source:
        number, data = line.strip().split(": ", 1)
        number = int(number)

        if number == expected:
            output.write(f"ACK {number}\n")
            print("Received:", data, "ACK", number)
            expected += 1
        else:
            output.write(f"NACK {number}\n")
            print("Incorrect frame:", number, "NACK")

print("Responses saved in Receiver_Buffer")

16. RAW SOCKET - TCP PACKET SNIFFER
------------------------------------------------------------
AIM:
To capture TCP packets and display source port, destination port and flags.

PROCEDURE:
1. Create a raw socket.
2. Capture incoming IP packets.
3. Check whether the IP protocol field is TCP (6).
4. Read the TCP header.
5. Display source port, destination port and TCP flags.

CODE (tcp_sniffer.py):
-------------------------------
import socket
import struct

s = socket.socket(socket.AF_INET, socket.SOCK_RAW, socket.IPPROTO_TCP)
print("Capturing TCP packets... Press Ctrl+C to stop")

while True:
    packet, addr = s.recvfrom(65535)

    ip_header = packet[:20]
    iph = struct.unpack("!BBHHHBBH4s4s", ip_header)
    ip_header_len = (iph[0] & 15) * 4

    tcp_header = packet[ip_header_len:ip_header_len+20]
    if len(tcp_header) < 20:
        continue

    tcph = struct.unpack("!HHLLBBHHH", tcp_header)
    source_port = tcph[0]
    dest_port = tcph[1]
    flags = tcph[5]

    print("Source Port:", source_port)
    print("Destination Port:", dest_port)
    print("Flags:", flags)
    print("-------------------")

17. RAW SOCKET - ICMP PACKET SNIFFER
------------------------------------------------------------
AIM:
To sniff ICMP packets and display source IP, destination IP, TTL, type and code.

PROCEDURE:
1. Create a raw socket for ICMP.
2. Capture packets.
3. Read the IP header to get source IP, destination IP and TTL.
4. Find the ICMP header after the IP header.
5. Display ICMP type and code.

CODE (icmp_sniffer.py):
-------------------------------
import socket
import struct

s = socket.socket(socket.AF_INET, socket.SOCK_RAW, socket.IPPROTO_ICMP)
print("Capturing ICMP packets... Press Ctrl+C to stop")

while True:
    packet, addr = s.recvfrom(65535)
    if len(packet) < 28:
        continue

    iph = struct.unpack("!BBHHHBBH4s4s", packet[:20])
    ihl = (iph[0] & 15) * 4

    ttl = iph[5]
    src = socket.inet_ntoa(iph[8])
    dst = socket.inet_ntoa(iph[9])

    icmp_type, icmp_code = struct.unpack("!BB", packet[ihl:ihl+2])

    print("Source IP:", src)
    print("Destination IP:", dst)
    print("TTL:", ttl)
    print("ICMP Type:", icmp_type)
    print("ICMP Code:", icmp_code)
    print("-------------------")

18. RAW SOCKET - IP HEADER SNIFFER
------------------------------------------------------------
AIM:
To capture packets and display IP header fields.

PROCEDURE:
1. Create a raw socket using AF_INET and SOCK_RAW.
2. Capture IP packets.
3. Unpack the IP header.
4. Extract version, header length, TTL and protocol.
5. Convert source and destination addresses into readable IP format.
6. Display the fields.

CODE (ip_sniffer.py):
-------------------------------
import socket
import struct

s = socket.socket(socket.AF_INET, socket.SOCK_RAW, socket.IPPROTO_IP)
print("Capturing IP packets... Press Ctrl+C to stop")

while True:
    packet, addr = s.recvfrom(65535)
    if len(packet) < 20:
        continue

    iph = struct.unpack("!BBHHHBBH4s4s", packet[:20])

    version = iph[0] >> 4
    header_length = (iph[0] & 15) * 4
    ttl = iph[5]
    protocol = iph[6]
    source = socket.inet_ntoa(iph[8])
    destination = socket.inet_ntoa(iph[9])

    print("Version:", version)
    print("Header Length:", header_length)
    print("TTL:", ttl)
    print("Protocol:", protocol)
    print("Source IP:", source)
    print("Destination IP:", destination)
    print("-------------------")
